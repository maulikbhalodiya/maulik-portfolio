01 · Independent Project

An SEO and schema engine for WordPress, built as an independent open source project. It analyses content, generates structured data and manages the metadata that search engines read, as a plugin rather than a pile of site-specific overrides.

Created by Maulik Bhalodiya. Not affiliated with Qrolic Technologies, and not client work.

02 · Subsystems

Subsystems

Nine subsystems across three states. The status is the honest state of each one, not an intention.

Modules · IMPLEMENTED

The unit the rest of the engine is assembled from. Each module owns one area of behaviour and registers through WordPress hooks rather than being called from a template.

Settings · IMPLEMENTED

Configuration surface, stored through the WordPress options API with validation on write and capability checks on read. Settings are typed rather than free text, so an invalid value cannot reach the engine.

Metadata · IMPLEMENTED

Reading and writing the metadata that describes a post to a search engine, keyed per post type and kept out of the post content itself.

Schema · IN PROGRESS

Structured data generation from content shape, with the type resolution and required property rules still being worked through. Partially working today.

REST · IN PROGRESS

A public read API over the generated output, so the same analysis is available to whatever consumes it. Endpoint surface is still settling.

Sitemaps · IN PROGRESS

XML sitemap generation driven by the same content rules as the rest of the engine, so a URL cannot be included in a sitemap and excluded from the metadata.

Content Analysis · PLANNED

The semantic pass that decides what a piece of content is about and which schema type fits it. Not started, and listed here so the roadmap is honest rather than optimistic.

Redirects · PLANNED

Redirect management as a first class citizen rather than a separate plugin, with the import path still to be decided. Not started.

404 Monitoring · PLANNED

Recording and surfacing not found hits so a redirect can be created from evidence. Not started.
