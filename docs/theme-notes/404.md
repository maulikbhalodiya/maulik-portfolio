# Archived comments from `templates/404.html`

These notes were originally plain HTML comments written directly inside
the block theme file `templates/404.html`. WordPress runs that file through `do_blocks()`,
and `WP_Block_Parser` keeps any `<!-- ... -->` that is not a block delimiter
(`<!-- wp:` or `<!-- /wp:`) as freeform HTML and renders it verbatim. The
comment text was therefore being printed as body copy in front of real
visitors on every page.

They have been moved here, word for word and with their original tab
indentation, so the architectural rationale is preserved without being shown
to visitors. Nothing below is paraphrased or summarised. Each fenced block is
the inner text of one original comment, in the order it appeared in the file.

## Comment 1 of 1 (originally at templates/404.html line 1)

```text
	CONDITION: no route matched. A block theme must ship a real 404.html as a
	file, because the design's 404 is an inline prototype fallback with no URL of
	its own.

	The eyebrow "404 / ROUTE NOT RESOLVED" is taken verbatim from that design and
	is correct as written. Do not rewrite it into something softer or friendlier.
	The square bullet motif opens the eyebrow here exactly as it opens every
	homepage section eyebrow: an 8x8px amber span, aria-hidden, because a
	decorative shape must never reach a screen reader.

	A template is block markup. It is parsed, not executed, so it cannot call
	esc_html__() and literal text here is NOT translatable. That is the reason
	every other template in this theme leaves its headings empty rather than
	filling them with placeholder English. This file is the deliberate exception:
	a 404 view with no message is useless, so the design's own short strings are
	kept here and the translatable versions live in patterns/404.php.
```
